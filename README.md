# Aquarium Graphics Project

## Overview

This project is part of my Computer Science 1 coursework at New Mexico State University (NMSU).

The goal of this project is to create an underwater aquarium scene using Java and the custom Painter graphics library provided for the course.

The aquarium will include different sea creatures, decorative underwater elements, and Java methods and loops to organize and repeat drawing operations.

## Technologies Used

- Java 17
- Visual Studio Code
- Git and GitHub
- NMSU Painter Graphics Library

## Planned Features

- Colorful fish in different sizes and colors
- Sharks with different sizes and orientations
- Underwater seaweed and coral
- Decorative bubbles
- Reusable Java methods
- Loops to create repeated elements
- Optional animation and randomized elements

## Running the Project

The project requires Java 17 and the Painter graphics library.

On Windows, compile the program from the project directory:

```powershell
javac -cp "lib/painter-canvas-17.jar" Aquarium.java
```

Run the program:

```powershell
java -cp ".;lib/painter-canvas-17.jar" Aquarium
```
